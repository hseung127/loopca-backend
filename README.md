# 스마트 암기카드 - Backend
 
## 기술 스택
`Java` `Spring Boot` `MySQL` `JPA` `Docker` `AWS EC2` `GitHub Actions`
 
## 주요 기능
- JWT 인증 기반 회원가입/로그인
- 그룹/카드/학습 데이터 DB 스키마 설계 및 CRUD API
- 학습 종료 시 별표 상태 저장 및 학습 이력 관리
- 학습 회차 완료 시 포인트 적립 및 저장
  
## 인프라
- AWS EC2 서버 배포
- MySQL Docker 컨테이너 운영
- GitHub Actions CI/CD 파이프라인 구성
